# nux-workshop

Workshop repository for NUX. Private.

## Layout

```
docs/      specs and decisions (Markdown is the source of truth)
src/       implementation
tests/     tests
```

## Getting started

1. Clone: `git clone https://github.com/mr-phariyawit/nux-workshop`
2. Branch from `main`, open a PR. Never push to `main` directly.
