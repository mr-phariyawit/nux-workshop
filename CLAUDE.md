# nux-workshop

## Rules
1. Never use `--force` on git. Never push to `main`. Branch + PR always.
2. Never `git commit --amend`.
3. Spec first: write or update the relevant doc under `docs/` before code.
4. Tests accompany every behaviour change.

## Layout
- `docs/` — specs, ADRs, plans (source of truth)
- `src/` — implementation
- `tests/` — tests
